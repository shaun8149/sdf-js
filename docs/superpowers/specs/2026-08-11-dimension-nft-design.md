## 策展结构：韵脚 + 独白 + 静物 + 升维图

### 1. 跨维韵脚（主线）

同一个形状在三个维度的三次转世。8 韵部：

| 韵部 | 2D | 3D | 4D |
|---|---|---|---|
| 圆韵 | 圆 | 球 | 超球 (glome) |
| 方韵 | 方 | 立方 | 超立方 (tesseract) |
| **环韵** | 圆环 | 环面 | **spheritorus + Clifford 双环面（全表唯一分叉）** |
| 心韵 | 心 | 心旋转体 | 心×圆对偶柱 |
| 星韵 | 星 | 星柱 | 星×星对偶柱 |
| 齿轮韵 | 齿轮 | 齿轮柱 | 齿轮×圆对偶柱 |
| 花韵 | 花 | 花柱 | 花×花对偶柱 |
| n-gon 韵 | 正 n 边形 | 棱柱 | 对偶棱柱（n 滑向 ∞ = **方圆连续熔化**） |

- 4D 基建已存在：`sdf-js/apps/fourd/`（超球/超立方/超对偶柱/spheritorus/duotorus + duoprism 生成器 + 六平面旋转 + slice/thick/onion 三模式，#414）
- 4D 呈现以**切片**为主（4D SDF 固定 w=w₀ 即严格 3D SDF，零近似）；onion 少见档；**thick 稀有档**（w 测深映射进本件作品自己的颜料序列，不用光谱色）
- 族内稀有度坡度：**2D 常见 → 3D 少见 → 4D 稀有**（用户确认符合收藏节奏直觉）

### 2. 独白轨（每个维度只有它能说的话）——全要

- **2D 独白**：BOB 血统六景（仙人掌+门/BTC、花树帆船、拱桥、建筑群远/近、砖墙）+ BTC/MOON 彩蛋原样继承
- **3D 独白（圣物殿）**：犹他茶壶、门格海绵、Gyroid 极小曲面、形而上学广场（球+柱+拱门+长影，de Chirico）
- **4D 独白**：**24-cell 孤韵**——四维独有正多胞体，元数据直书 `2D 亲属：不存在 / 3D 亲属：不存在`，稀缺性由数学担保

### 3. 2D 经典静物（2026-08-12 收缩裁定：放弃编年史，回到"剪影即语义"）

> 用户裁定：2D 野心收小，不做十纪元编年史；回到最初提案的经典静物清单。
> 选件原则不变——**剪影即语义**：一眼剪影就能读出全部含义的物体。

- **莫兰迪瓶罐**：三五个瓶子的组合，静物画的世界语；点彩 + 暖纸天生莫兰迪气质
- **塞尚果盘 / 梵高的椅子**：艺术史的日常物致意
- **茶壶 · 伞 · 剪刀 · 钥匙 · 眼镜**：日常物的诗意（茶壶与 3D 圣物殿互文）
- **月相 · 日食 · 纸飞机 · 灯塔 · 风车**：天文与孤独感系列

（era/纪元 trait 轴随编年史一并取消。）

### 4. 升维图（超稀有档）

一张画布同台三个维度：平面的圆、光影里的球、超球的切片，站同一条地平线、投同一盏灯的影。**100 件**（对标 BOB 的 BTC to moon 体量）。
