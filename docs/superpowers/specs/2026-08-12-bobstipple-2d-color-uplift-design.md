# bobStipple 2D 色彩升格 — 把 3D 的鲜艳层次带给 2D

> 状态：spec 草案，待用户批准后动工。
> 背景：genlab 103 件 2D 点彩版（png2）整体发灰发闷；DIMENSION 3D 点彩（球/锚对比图）鲜艳、丰富、多层次。用户要求：查明原因，把 3D 的色彩机制赋予 2D。

## 一、为什么 3D 比 2D 好看（代码级诊断）

同一个渲染器 `bobStipple.js` 里藏着**两条完全不同的取色路径**（bobStipple.js:829-856）：

### 3D 路径（好看的那条）= BOB 血统三件套

| 机制 | 代码位置 | 视觉效果 |
|---|---|---|
| **① 策展颜料**：从 BOB 20 组手工颜料（`BOB_PIGMENTS`）hash 选 2 组做 pal/pal2 | bobStipple.js:40, `pickBobPalettes` | 每种颜色都是艺术家挑过的高对比颜料，不存在"脏色" |
| **② 调色板漫步 + 双板交替**：每 cell 画 N 层笔触，第 k 层取 `pal[(colorBase+k) % len]`，奇数层换 pal2 | bobStipple.js:858-864 | 一块表面由 4-6 种颜料**编织**而成 → 修拉式光学混色，远看震颤发光 |
| **③ 光照→密度轴**：`density = 1 − 0.92·I²` + 随机舍入，亮面笔触稀疏（纸色/底色透出）、暗面密实 | bobStipple.js:815-822 | 明暗结构 + 白纸呼吸感（你截图里球顶的白色闪光就是它） |

另加 regionOffset 把 background/ground/object 分进不同色窗——天、地、物各有色域。

### 2D 路径（发闷的那条）= 语义丢弃 + 满密度混浊（实测修正版）

png2 实际走的是 `bobPaletteMode`（默认开）——BOB 颜料在用，但用错了地方：

- **LLM 语义色被丢弃**：2D 命中后 colorBase = `hitLayerIdx*3 + 奇偶偏移`（bobStipple.js:843-856）——每个 SDF 按**序号**在 hash 选出的调色板里随机开 3 色窗（即用户观察到的"按 SDF 随机赋两色"）。苹果是不是红全凭运气；genlab 件动辄 10-20 层 SDF，色窗在调色板上散射，语义结构全碎；
- **没有密度轴**：2D 路径明确跳过 Lambert 调制（bobStipple.js:813 注释"2D layer 跳过"），`effBrushLayers` 恒定满密度；
- 满密度下 pal/pal2 交替 5 层笔触 → 每个 cell 混 5 支无关颜料 → 光学混色变成杀手，邻近 cell 平均成灰。

结果：**满密度、语义无关的多颜料混浊织网**。白纸不呼吸、没有明暗、色块与物体错位。锚那张是教科书症状。

**一句话：3D 好看不是因为它是 3D，而是因为它独占了 BOB 的三件套。2D 被隔离在一条退化路径上。**

## 二、改法：给 2D 接上三件套（保语义色）

约束：2D 件的颜色带语义（苹果必须红、竹子必须绿），不能像 BOB 原版那样整幅 hash 随机换色。因此核心设计是**"语义锚定的 BOB 化"**——色相听 LLM 的，颜料和织法听 BOB 的。

### 改动 ① 颜料升格：LLM RGB → BOB 织谱（替换 expandColorPalette）

新函数 `buildWeavePalette(baseRGB)`：

1. 把 20 组 `BOB_PIGMENTS` 摊平成全局颜料池（约 300 支，去重）；
2. 按**色相距离**（HSL 加权：hue 为主、sat/lum 为辅）从池中选出离 baseRGB 最近的 K 支（K≈5，可调），构成该层的**主织谱 pal**——苹果红会捞到 BOB 各组里的正红/橘红/洋红，全是策展级颜料；
3. 再选出"次近但偏离一档"的 K 支（邻近色相带 + 少量低权重补色）构成 **pal2**；
4. 笔触层沿用 3D 的漫步+交替：第 k 层取 `pal[(colorBase+k)%K]`，奇数层用 pal2。

灰/白/黑等低饱和 base（如纸、石头）单独处理：从颜料池选低饱和支 + 允许注入 1 支高饱和"跳色"（BOB 的 signature 震颤来源），跳色权重可调。

### 改动 ② 2D 假光照 → 接通密度轴

2D 没有 Lambert，但 SDF 本身就是光：

- **轮廓光**：`I_edge = clamp(-sdf(p) / falloff, 0, 1)` —— 形体内部离边越远越"亮"；
- **方向光**：对 2D SDF 求数值梯度，与固定光向（默认左上，经典静物光）点积 → `I_dir`；
- 合成 `I = mix(I_edge, I_dir, w)` 后**原封套用 3D 公式** `density = 1 − 0.92·I² + 随机舍入`。

效果：形体中央亮面笔触稀疏、白纸透光；轮廓一圈密实变暗，天然勾边；背景保持中密度。这正是 3D 球"顶白底彩"的观感来源，公式 1:1 复用，血统不变。

### 改动 ③ 背景分区点彩

背景不再用 bgFn 单色 + LLM 微扩展，而是把 bgFn 的渐变色作为 base 走同一套 `buildWeavePalette`，并给背景独立 colorBase 窗口（类比 3D 的 `regionOffset.background`）——天空获得和 3D 一样的多颜料织毯感。

## 三、实施边界

- **只改 `bobStipple.js`**，新增选项 `colorMode: 'weave'`（默认保持现状 `'llm'`，不破坏既有调用方）；genlab 的 view2.html 传 `colorMode: 'weave'` 即可全量重渲。
- 全部取色由现有 seed-rng 驱动，同 seed 同图（NFT 确定性不变）。
- 规模：一个新函数（~50 行）+ 2D 密度分支（~15 行）+ 背景路径改造（~10 行）。不动 3D 路径、不动笔触几何、不动网格/bend。
- 验收：锚/帆船/吉他/苹果四件 before/after 对照 + 全量 103 件重渲 png3 目检。

## 四、待拍板的三个旋钮

1. **K 与保真度**：K 越大越鲜艳但离语义色越远。默认 K=5，是否给"苹果红"这类强语义件收紧到 3？
2. **光向**：固定左上（全系列统一、经典）vs 按 seed 每件随机（更生成艺术）。建议固定左上。
3. **跳色权重**：低饱和区注入高饱和跳色是 BOB 震颤的灵魂，但会让"莫兰迪瓶罐"这类灰调件变跳。建议默认低权重 0.15，莫兰迪类靠 K 内低饱和支自然压住。
